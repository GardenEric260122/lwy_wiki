## 3. 三层引力范围理论

### 3.1 理论主张（一手：详解星球的引力范围理论）

每个星球存在**三个同心引力范围**，从内向外：

```
[内围吸引力范围] → [旋转引力范围] → [外围吸引力范围]
```

| 范围 | 功能 | 示例（地球） |
|------|------|------------|
| 内围吸引力范围 | "固定卫星的地方" | 约500km，地球同步卫星位置 |
| 旋转引力范围 (自转引力范围) | 占引力范围的绝大部分 | 向外推出，禁止其他天体靠近 |
| 外围吸引力范围 | 行星在此范围内运动 | 行星在此层与旋转层之间运动 |

### 3.2 证据与推导

- **观察基础**：在深圳观测冬至太阳位置，测得地球运动范围
- **计算过程**：（一手：详解星球的引力范围理论）
  - 地球南北方向运动距离 ≈ 太阳半径的 1/3
  - 地球东西方向运动距离 ≈ 太阳半径的 2/3 多
  - → 证明地球在太阳引力层的特定区间运动
- **月球验证**：（一手：详解星球的引力范围理论/痛批万有引力）
  - "地球外围的吸引力和旋转引力分界线也就是2万多千米"
  - 月球在地球的"外围吸引力范围和旋转引力范围之间运动"
  - 这一模型解释了为什么月球不撞向地球也不飞走

### 3.3 对牛顿引力的替代

- 星球之间的力不是相互吸引，而是**粒子运动产生的推斥力**（一手：痛批万有引力）
- "旋转引力范围向外推斥，不允许任何星球/天体向地球靠近"（一手：详解星球的引力范围理论）
- 这一模型同时解释了：
  - 为什么地球靠近太阳（受外围吸引力范围影响）
  - 为什么地球远离太阳（受旋转引力范围的推斥力影响）
  - "我们的牛顿能解释这个地球远离太阳运动的力吗？"（一手：痛批万有引力）

### 3.4 宇宙学推论（一手：详解星球的引力范围理论）

- 引力范围机制"保证星球之间不能够相互合并碰撞"
- 因此LIGO探测到的黑洞合并是"编造"的（一手：中子星视频）
- 此模型替代了整个天体物理学

## 6. 否定光合作用

### 6.1 核心主张（一手：痛批光合作用/最新实验证明/生物课堂）

- **二氧化碳不是光合作用的原料**
- 植物的生长不需要CO2
- 气孔（stomata）不存在或不能吸收CO2
- 叶绿体不可能吸收CO2分子

### 6.2 "实验"证据（一手：最新实验证明）

**套袋实验（2024年3月2-11日，共9天）：**

实验设计：
```
3盆小麦幼苗：
  A: 密封+小苏打+白醋→产生CO2
  B: 密封+无添加
  C: 密封+通电充入氧气
```

观察结果：
- B（无CO2）生长状态"相当旺盛"，"不比那两盆差"
- B甚至比A（加CO2）"长得还好"
- C（充氧气）生长状态同样良好

**结论错误归因**：
- "如果光合作用需要二氧化碳原料，几个小时内就会把袋内CO2消耗完"
- "密封一天都不行"→没死→所以不需要CO2
- 再加上套袋葡萄几个月还能成熟→进一步"证明"

**气孔不存在论证**（一手：痛批光合作用/生物课堂）：
- "我观察了大部分叶片，没有看到什么气孔"
- 叶片表面"光滑""致密""是不透气的"
- CO2分子量太大（"二氧化碳分子量很大，很多原子构成"）→不可能进入叶绿体
- 但"太阳光的粒子（高能电子）"体积小运动快→可以直接进入叶绿体

### 6.3 植物营养来源替代解释（一手：生物课堂）

- 植物营养通过根部→导管（道管）输送
- 导管"就是输送水分"的主要通道
- 否认光合作用合成葡萄糖的化学反应机制

### 6.4 对教育制度的攻击（一手：痛批光合作用）

## 14. 反科学论证修辞体系

### 14.1 标准论证模板（推断）

```
1. 提出问题："书本上说……"
2. 质疑权威："他们正确吗？"
3. 观察证据："我实际观测/实验看到……"
4. 挑战："你能解释吗？不讲道理就枪毙你"
5. 迫害指控："恶势力/权威要压死我"
6. 结论："所有旧理论都是错误的，我的理论才是正确的"
```

### 14.2 修辞特征

- **绝对的确定性**：从不使用"可能""或许"，永远使用"一定是错误的""绝对是正确的"
- **暴力语言**：枪毙、恶势力、地痞流氓、狗屎、垃圾
- **道德化科学**：不接受他的理论 = 阻碍科学发展 = 邪恶
- **民粹主义**："世界是忽悠人的世界" "全世界的广大劳动人民群众"被精英欺骗
- **自我神化**：将自己置于全世界的学术权威之上，每一理论都宣称"颠覆传统认知"、"改变科学"
- **虚构建制**：创造"联合国科学研究批判大会""南非阿玛利亚科学高等研究所"等虚假机构来支持自己
- **互联网迷因化**：引入孙笑川、田所浩二、下北泽大学等网络迷因元素，模糊真实与虚构的边界

### 14.3 理论间的一致性（推断）

尽管表面上理论独立，李文亚的体系在深层统一：

- **天文学 → 物理学**：三层引力范围理论统一解释天体运动和力学
- **物理学 → 生物学**：粒子理论延伸至光合作用（高能电子替代CO2）
- **生物学 → 医学**：黑体生物理论源自微生物研究
- **一切 → 迫害叙事**：所有理论的不被接受都归因于同一群"恶势力"
